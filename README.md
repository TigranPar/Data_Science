## Գործարկում

Բացել տերմինալը ծրագրի պանակում և կատարել՝

```powershell
python -m pip install -r requirements.txt
python -X utf8 run_all.py
```

Առանձին բաժին գործարկելու օրինակ՝

```powershell
python -X utf8 sample_tasks.py
```

Ստուգումների գործարկում՝

```powershell
python -X utf8 verify_solutions.py
```

`-X utf8` դրոշը ապահովում է հայերեն տեքստի ճիշտ արտածումը Windows-ում, այդ թվում՝ արտածումը ֆայլ ուղղորդելիս։ Լուծումները ստուգվել են Python 3.14, pandas 3.0.3 և NumPy 2.4.4 տարբերակներով։

## Սկզբնական տվյալներ և ընդունված պայմաններ

- Պայմաններում թվային `s` և `s1` Series-ները սահմանված չեն։ Յուրաքանչյուր բաժնի համար ընտրվել է առանձին օրինակ՝ `main()` ֆունկցիայի մեջ։ Այլ տվյալներով աշխատելու համար կարելի է փոխել այդ օրինակը։
- Յուրաքանչյուր առաջադրանք կատարվում է սկզբնական տվյալների հետ՝ մյուս առաջադրանքներից անկախ։
- Հիմնական թվային առաջադրանքները նախատեսված են ոչ դատարկ Series-ների համար՝ առանց բացակայող արժեքների։ Թվաբանական բաժնում ինդեքսի պիտակները ամբողջ թվեր են․ զույգ լինելը ստուգվում է պիտակի համար։ Օրինակում պիտակներն ու դիրքերը համընկնում են։
- `[a, b]` միջակայքը ներառում է երկու սահմանները։ «Մեծ» և «փոքր» պայմանները խիստ համեմատություններ են։
- «Series-ին գումարել 100» պայմանը մեկնաբանվում է որպես յուրաքանչյուր արժեքին 100 գումարելու գործողություն։
- `round()`-ը կիրառում է pandas-ի կլորացումը․ կես արժեքները կլորացվում են դեպի մոտակա զույգ ամբողջ թիվը, օրինակ՝ 2.5 → 2, 7.5 → 8։
- Երբ ընդհանուր գումարը զրո է, տոկոսային բաժինները որոշված չեն․ վերադարձվում է `NaN` արժեքներով Series։
- «Բոլոր տարրերը ճշմարիտ են» պայմանը ստուգվում է `all()`-ով։ Առանց բացակայող արժեքների թվային շարքում զրոն կեղծ է, իսկ ոչ զրոյական թիվը՝ ճշմարիտ։
- Տարրերի զույգ քանակի դեպքում միջին դիրքի տարր է համարվում երկու կենտրոնական տարրերից աջը։ Մի քանի հավասար առավելագույն արժեքների դեպքում վերադարձվում է առաջին համապատասխան պիտակը։
- Պիտակների առաջին տառերը ստուգվում են առանց մեծատառի և փոքրատառի տարբերակման։ Ոչ տողային և դատարկ պիտակները չեն հաշվվում a–m ստուգման մեջ։
- Միապաղաղության ստուգումները թույլատրում են հարևան հավասար արժեքներ․ ստուգվում են չնվազող և չաճող կարգերը։
- Մեկ տարրի միջին հիշողությունը հաշվվում է `nbytes / size` արտահայտությամբ՝ առանց ինդեքսի։ Ընդհանուր հիշողությունը հաշվվում է `memory_usage(index=True, deep=True)`-ով և բաժանվում 1024-ի։ Այստեղ ԿԲ-ն օգտագործվում է 1024 բայթ իմաստով։ Արժեքը կարող է կախված լինել միջավայրի տարբերակից և ինդեքսի ներքին քեշի վիճակից։
- NumPy-ի առաջադրանքում ընտրված են 0-ից 999 պատահական ամբողջ թվեր։ Պատահական թվերի գեներատորի սկզբնական արժեքը՝ 42, թույլ է տալիս կրկնել արդյունքը։ Ֆիբոնաչիի հաջորդականությունն սկսվում է 0, 1, 1, 2 թվերով, իսկ զանգվածի ինդեքսները՝ զրոյից։
- Նմուշի 2-րդ և 3-րդ առաջադրանքներում սկզբնական հավաքածուներ չկան։ Թվերի փոխարինման համար ընտրված է խառը Series, իսկ անունների հեռացման համար՝ հայկական անուններով Series։ Փոխարինվում են թվային արժեքները, ոչ թե տողերի ներսի թվանշանները։ Փոխարինող բառը «թիվ» է։ Տրամաբանական արժեքները չեն փոխարինվում։
- Անունների հեռացման ժամանակ ստուգվում է հայերեն «ա» տառը։ Հեռացվում են բոլոր համապատասխան անունները, իսկ մնացածների ինդեքսի պիտակները պահպանվում են։

## Տեղեկատու օրինակների ճշտումներ

- `prod()`-ը հաշվում է արտադրյալը։
- `std()`-ը հաշվում է ստանդարտ շեղումը․ լռելյայն՝ `ddof=1`։
- `empty`-ն հատկանիշ է և գրվում է առանց փակագծերի՝ `arr.empty`։
- `'a'`, `'b'`, `'c'`, `'d'` պիտակների դեպքում պետք է օգտագործել, օրինակ, `at['a']`։
- `iat`-ի համար պետք է նշել դիրքը, օրինակ՝ `iat[0]`։
- `index`-ը պարտադիր չէ, որ լինի `RangeIndex`․ տողային պիտակները կազմում են սովորական `Index`։
- `drop()`-ը հեռացնում է ըստ պիտակների, իսկ `take()`-ը ընտրում է ըստ դիրքերի։
- `duplicated()`-ը լռելյայն նշում է կրկնությունները՝ առաջին հանդիպման համար թողնելով `False`։
- `(s == 40).any()`-ը 40-ը փնտրում է արժեքների մեջ, իսկ `40 in s`-ը ստուգում է ինդեքսի պիտակները։
